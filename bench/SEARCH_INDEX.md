# Search index cost

Generated by `bench/search_index.py` with agno 0.2.0 on Linux-7.2.2-1-cachyos-x86_64-with-glibc2.44.

- CPU: 13th Gen Intel(R) Core(TM) i5-13420H (12 threads)
- Corpus: `code` profile; both settings use the same content
- Runs: 9 cold builds per setting per corpus, alternated
- The output directory is removed before every timed run.
- `lists+feeds` is the build phase that writes the search index; its delta isolates the index cost from content loading and page rendering.
